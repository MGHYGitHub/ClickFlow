# Windows 原生输入与录制

适用平台为 Windows 10 / 11。输入服务直接调用 `user32!SendInput`，录制采用 `WH_MOUSE_LL` / `WH_KEYBOARD_LL` 低级钩子，全局控制采用 `RegisterHotKey`。不依赖 Python、Java、AutoHotkey 或第三方输入库。

## 坐标与输入

- 应用清单声明 `PerMonitorV2`。捕获、录制、回放的坐标均为屏幕物理像素，可使用负坐标和多个显示器。
- 绝对移动使用 `MOUSEEVENTF_ABSOLUTE | MOUSEEVENTF_VIRTUALDESK`，按整个虚拟桌面换算。目标位置不在任意显示器内（包括多屏排列中的空白区）时停止并报告错误，不把坐标静默挪到屏幕边缘。
- 随机位置仅用于指定坐标的动作。使用鼠标当前位置时不随机移动鼠标；指定点加随机偏移后越界也会报错。
- 鼠标支持左、右、中键，单击、双击、移动、垂直滚轮、按下和释放。横向滚轮、侧键目前未建模。
- 键盘支持命名快捷键和 Windows 虚拟键按下/释放。示例：`Ctrl+C`、`Ctrl+Shift+S`、`Alt+Enter`、`Win+R`。快捷键字符串仅支持一组由 `+` 连接的按键；顺序组合需拆为多个动作。
- `F2 / F3 / F4 / F6 / F7` 是应用控制键，不能作为快捷键或原始键盘动作回放。`Ctrl+Alt+Delete` 等安全桌面行为不属于 `SendInput` 能力。
- 输入结构完整包含鼠标、键盘、硬件联合体，所有指针字段使用 `nuint`。本机 x64 ABI 检查结果为 `INPUT=40` 字节、联合体 `32` 字节、联合体偏移 `8` 字节。
- 检查 `SendInput` 返回的实际事件数。权限较高的目标窗口、安全桌面、非交互桌面等可能拒绝输入，此时运行进入错误状态，并尝试释放本任务按住的输入。

## 执行、暂停和停止

`AutomationEngine` 在工作线程串行执行任务。运行前对动作及选项做快照；运行期间编辑原配置不会改变当前任务。引擎一次只接受一个运行。

`DelayMs` 是动作前等待，`Count` 是动作重复次数，`IntervalMs` 是同一动作重复之间的间隔。等待动作使用 `IntervalMs` 作为等待时长，等待完成后才计入完成数量。单次录制事件不会被额外增加固定 10 毫秒间隔；同一动作零间隔重复或完全无等待的整轮循环设有 10 毫秒下限，避免忙循环。上述时序受 Windows 线程调度影响，不承诺硬实时精度。

倒计时、动作等待、循环等待均可取消，暂停期间不消耗等待时长。常规进度通知最多约每秒 20 次，最终状态立即通知。无限循环使用 `RepeatCount = 0`。

原生输入驱动实现可选接口 `IInputSuspension`。暂停时临时释放当前任务按住的鼠标和键盘，继续时恢复这些逻辑持有状态；暂停期间停止不会恢复输入。恢复会使用当时的鼠标位置，因此拖拽中暂停后建议先把指针放回预期位置再继续。

停止、异常、角落保护、正常完成均经过 `finally`，释放由本任务追踪的按住键和按钮。应用退出会等待当前运行清理完成。进程被操作系统强制终止时无法保证托管清理代码运行。

启用角落保护时，把鼠标移动到当前显示器任意角落的 2×2 像素区域即可停止。检查也覆盖倒计时、等待与暂停阶段。`F6` 可直接停止任务，`F4` 暂停或继续，`F3` 开始或停止。

## 录制行为

- 钩子忽略软件注入事件，避免回放录制自身。服务的 `Start`、`Stop`、`Dispose` 应在创建它的 UI Dispatcher 线程调用。
- `Captured` 和 `Error` 在该 UI 线程通知。钩子回调把动作排队，退出钩子后才交付给界面；`Stop` 同步冲刷待交付事件，调用方不应按 `IsRecording` 丢弃停止时的尾部事件。
- 不录制本应用窗口上的新鼠标动作或键盘操作。对于之前在外部开始的按住操作，即使释放时焦点已切回本应用，也会补齐释放，以保持回放完整。
- 忽略应用控制键；自动录制还排除 Win 组合、Alt+Tab、Alt+Esc、Alt+F4 等系统切换动作。Alt 按下会先暂存，确认属于普通按键/鼠标组合后再写入，避免过滤系统快捷键后遗留孤立 Alt 操作。手工添加的 `Win+R` 等普通快捷键仍可执行。
- 鼠标移动每 16 毫秒至多采样一次，忽略相同位置；按键自动重复和重复按下会去重。录制保存动作间的相对时间、鼠标位置和按下/释放；因此长按产生的系统自动重复文本不会逐字符重建。
- 最多 50,000 个动作，达到上限自动停止，并保留余量补齐已按住输入的释放。手动结束录制同样补齐释放事件。
- 键盘保存虚拟键，不保存屏幕截图或可识别的文本。但录制按键可以推导输入内容，配置文件应按私人数据保管。键盘布局、输入法或目标程序变化会影响回放；数字小键盘 Enter 等共用虚拟键的细节尚未单独建模。

## 验证范围

已进行输入结构 ABI 检查和使用模拟输入驱动的自动化测试。模拟测试覆盖启动倒计时/长等待取消、配置快照、重复启动互斥、暂停等待、暂停释放与继续恢复、暂停后停止不恢复、错误释放和角落停止等行为。

本轮已通过内置输入测试板发送真实 Win32 输入，接收区实际收到 3/3 次左键事件，文本框实际收到 `abc`。输入限定于本程序自己的测试板，过程与结果见 [验收记录](验收记录.md)。尚未完成真实录制回放和跨应用验收。以下项目仍应在空白测试窗口中检查：

| 场景 | 要检查的行为 |
| --- | --- |
| 双屏、负坐标、不同缩放比例 | 捕获点与实际点击一致；屏幕空白间隙报错 |
| 普通窗口、管理员窗口 | 同权限目标接收输入；拒绝输入时清楚报错 |
| 连点、双击、滚轮、拖拽 | 指定按钮与事件次序正确 |
| 倒计时/长按/拖拽中的暂停和停止 | 暂停释放、继续恢复、停止不恢复且无残留按住 |
| 点击、拖拽和普通键盘组合录制 | 轨迹与相对时序可回放，停止补齐释放 |
| Win 组合、Alt+Tab、Alt+F4、应用自身操作 | 不作为任务动作录入，没有孤立修饰键 |
| 全局快捷键已被其他程序占用 | 列出注册失败，界面按钮仍可操作 |
| 任意显示器四角保护 | 等待、暂停和执行期间均能停止 |
