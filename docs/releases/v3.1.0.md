# ClickFlow 3.1.0

面向 Windows 10 / 11 x64 的全新 C# / .NET 10 / WPF 自动点击器，重新整合原 Python 与 Java 项目的快速连点、多步骤流程、操作录制和托盘控制。

- 现代浅色 / 深色界面，步骤编辑、暂停 / 继续、角落急停和原生 SendInput。
- 支持导入两种旧版配置，使用原子保存与备份。
- 新增「版本与更新」：手动检查 GitHub 最新稳定版本，下载 EXE 并核对 SHA-256；退出后手动替换，配置保留。
- 完整源代码、回归测试、可重复构建脚本与 GitHub Actions 发布流程一并公开。

下载 `ClickFlow-3.1.0-win-x64.exe` 直接运行，或下载 ZIP 获取软件、使用说明与运行时许可。已内置 .NET，无需单独安装运行时。当前 EXE 未作代码签名。

源码包为 `ClickFlow-3.1.0-source.zip`，校验清单为 `SHA256SUMS.txt`。`update.json` 为 API 限流时使用的官方备用更新元数据。主程序不会启动即执行任务，也不会静默下载或安装更新。完整验证记录及待验证场景见仓库 `docs/验收记录.md`；Windows 10、混合 DPI 多屏及完整真实录制回放仍需进一步实机验收。
